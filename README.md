# Sudar for Mac

Sudar 是一款 macOS 剪贴板管理器，支持搜索复制历史、固定常用内容、管理文本片段，以及预览文字、图片和文件。

Sudar is a clipboard manager for macOS 14 or later. Search copied items, pin frequently used content, organize reusable text snippets, and preview text, images, and files. Clipboard history is stored on your Mac.

## 支持 / Support

- 从菜单栏点击 Sudar 图标打开历史记录；在搜索框输入关键词筛选。
- 选择条目后按回车复制；启用“自动粘贴”后可直接粘贴到前台应用。
- 自动粘贴需要在“系统设置 > 隐私与安全性 > 辅助功能”中允许 Sudar。尚未允许时，可以先复制条目，再在目标应用中按 Command+V。
- 在 Sudar 菜单中打开“设置”，可调整快捷键、历史容量、忽略应用、预览区域和文本片段。
- 搜索框为空时按 Delete 删除选中条目；有搜索文字时 Delete 正常删除文字。
- 如自动粘贴失效，请先检查设置中的“自动粘贴”和辅助功能权限，再退出并重新打开 Sudar。

Open Sudar from the menu bar and type to search. Press Return to copy the selected item. Automatic paste is optional and requires macOS Accessibility permission; without it, copy an item and paste with Command+V in your destination app. Settings includes shortcuts, history limits, ignored apps, previews, and reusable snippets.

Report a problem or request help using [GitHub Issues](https://github.com/allonli/sudar-support/issues). Include your macOS version, Sudar version, and reproduction steps. **Do not post passwords, personal clipboard contents, or private files.** GitHub issues are public.

## 隐私 / Privacy

阅读 [隐私政策 / Privacy Policy](privacy.md)。Sudar 没有开发者运营的剪贴板服务器，不上传剪贴板历史，也不包含广告或跟踪 SDK。
